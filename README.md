## Descripción

CEmestre es un proyecto desarrollado para apoyar la construcción de horarios de matrícula mediante el análisis de la información de los cursos y sus restricciones.

Esta etapa corresponde al **paradigma imperativo** y está desarrollada en **lenguaje C**.

## Objetivo

Desarrollar un sistema capaz de procesar información académica para facilitar la construcción de horarios, considerando:

* Cursos disponibles.
* Requisitos.
* Correquisitos.
* Horarios.
* Choques de horario.
* Relaciones entre cursos.
